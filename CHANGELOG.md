# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-28

### Added

- Initial release
- Automatic OCR processing when images are added to vault
- Manual OCR via command palette
- Settings panel with configuration options:
  - Toggle automatic processing
  - Configure cache folder location
  - Exclude specific folders
  - Toggle notifications
- Swift CLI tool using macOS Vision framework
- Support for PNG, JPEG, GIF, WebP, BMP, and TIFF images
- Automatic language detection
- Install script for easy deployment to vaults
